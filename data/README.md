# Organización ilustrativa de datos

Repositorio didáctico; destinado a practicar organización y control de versiones. No se utilizan datos reales ni se incluyen conjuntos de datos simulados.

- [raw](raw/README.md) representa el lugar de los datos originales.
- [processed](processed/README.md) representa el lugar de los datos derivados.
- La descripción hipotética de las muestras se organiza en [metadata](../metadata/README.md).

Ambas subcarpetas contienen solamente documentación y están excluidas de la incorporación ordinaria de archivos de datos mediante `.gitignore`.
