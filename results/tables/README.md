# Tablas de resultados

Esta carpeta contiene las tablas organizadas para representar los resultados del análisis metagenómico.

## Contenido

- `tabla_microorganismos.csv`: identificación de microorganismos potencialmente degradadores de petróleo.
- `tabla_genes.csv`: genes asociados a la biodegradación de hidrocarburos y sus funciones.
- `tabla_abundancia.csv`: abundancia relativa de microorganismos en las muestras.
- `tabla_funciones.csv`: funciones metabólicas relacionadas con la degradación de hidrocarburos.

Los archivos son ejemplos didácticos y no representan resultados experimentales reales.
