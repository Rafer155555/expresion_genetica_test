# Análisis de agrupamiento (Clustering)

Esta carpeta contiene los resultados del análisis de agrupamiento jerárquico (clustering), realizado a partir de los datos simulados de abundancia microbiana y genes funcionales.

## Objetivo

Identificar agrupamientos de muestras que presenten perfiles de abundancia similares, mediante el análisis de sus distancias y relaciones de similitud.

## Contenido

Se almacenarán los siguientes resultados:

- `resultados_clustering.zip`
- `Dendogramas y tablas.cvs`

## Metodología

Se utilizará el método de agrupamiento jerárquico con enlace promedio (average linkage) y la distancia Bray-Curtis para comparar los perfiles de abundancia relativa.

El análisis se realizará por separado para suelo y agua.

## Interpretación

Los dendrogramas permitirán visualizar las relaciones de similitud entre las muestras y reconocer posibles patrones de agrupamiento según sus perfiles de abundancia.

**Nota:** Los resultados son simulados y no representan evidencia experimental de relaciones ecológicas o procesos de biodegradación.
