
# Interpretación de resultados estadísticos

Esta carpeta contiene los documentos destinados a describir, analizar e interpretar los resultados obtenidos mediante los diferentes procedimientos estadísticos aplicados a los datos simulados del proyecto.

## Objetivo

Integrar los resultados de los análisis estadísticos y de las representaciones gráficas para identificar patrones hipotéticos de abundancia microbiana y genes funcionales en muestras de suelo y agua amazónicas.

## Consideraciones para la interpretación

Los resultados se analizarán considerando las diferencias entre las matrices ambientales de suelo y agua.

Se distinguirá entre la abundancia de microorganismos y la abundancia de genes funcionales, evitando interpretar ambos conjuntos de datos como variables equivalentes.

La presencia o abundancia simulada de determinados microorganismos o genes no demuestra actividad metabólica ni degradación efectiva de hidrocarburos.

## Nota

Todos los datos y resultados de este proyecto son simulados y tienen fines exclusivamente académicos. Las interpretaciones describen patrones hipotéticos y no constituyen evidencia experimental.
