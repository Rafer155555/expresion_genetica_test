# Figuras de resultados

Esta carpeta contiene las representaciones gráficas del análisis metagenómico.

## Contenido

- `diversidad_microbiana.png`: representación de la diversidad de microorganismos.
- `abundancia_taxonomica.png`: distribución de microorganismos identificados.
- `genes_biodegradacion.png`: representación de genes asociados a la degradación de hidrocarburos.
- `rutas_metabolicas.png`: esquema de rutas metabólicas relacionadas con la biodegradación del petróleo.
- `comparacion_muestras.png`: comparación de comunidades microbianas entre muestras.

Las figuras se incorporarán como ejemplos de visualización de resultados metagenómicos.
