# Control de calidad de secuencias

## Descripción

Esta carpeta contiene la documentación del control de calidad de las secuencias metagenómicas utilizadas en el proyecto.

## Contenido

- Evaluación de calidad de lecturas.
- Identificación de secuencias de baja calidad.
- Revisión de calidad por posición.
- Evaluación de contenido GC.
- Identificación de adaptadores y secuencias contaminantes.
- Reportes de calidad antes y después del procesamiento.

## Herramientas bioinformáticas

Se consideran las siguientes herramientas para representar el flujo de control de calidad:

- FastQC: evaluación de calidad de secuencias.
- MultiQC: integración de reportes de calidad.
- Fastp: evaluación y filtrado de lecturas.

## Objetivo

Evaluar la calidad de los datos metagenómicos para garantizar su idoneidad antes de realizar los análisis posteriores.

**Nota:** Los reportes incluidos en este proyecto serán simulados.
