# Plantilla ilustrativa de metadatos

Esta carpeta muestra cómo se describirían muestras de un proyecto de metagenómica ambiental. No contiene registros de muestras reales o simuladas.

- [muestras_plantilla.csv](muestras_plantilla.csv) contiene solo encabezados.
- [diccionario_muestras.csv](diccionario_muestras.csv) explica los campos propuestos.

Los nombres de campos usan caracteres ASCII para facilitar su manejo en herramientas de texto. El formato es CSV con coma como separador y codificación UTF-8.

En este ejercicio la plantilla se conserva vacía. El grupo puede mejorar la documentación del esquema mediante commits y pull requests. Las condiciones y ambientes descritos son categorías conceptuales, no observaciones realizadas.
