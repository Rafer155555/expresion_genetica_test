# Documentación del caso conceptual

El [plan conceptual](plan_conceptual.md) describe el contexto científico usado para practicar organización y control de versiones. No es un procedimiento ejecutable ni un registro de análisis realizados.

El grupo puede ampliar aquí la justificación del proyecto, las convenciones de archivos y la explicación de su colaboración mediante Git y GitHub. El trabajo permanece dentro del alcance didáctico indicado en el [README principal](../README.md).
